EXAMPLE DATA FLOW:

IGDB API Response:
{
  "release_dates": [
    {
      "date": 1488499200,
      "platform": {"name": "Nintendo Switch"},
      "region": 2,
      "human": "Mar 03, 2017"
    }
  ]
}
        ↓
Parsed to GameObject:
game.release_dates = [
  {
    "platform_name": "Nintendo Switch",
    "region_id": 2,
    "release_date": "2017-03-03",
    "human_readable": "Mar 03, 2017"
  }
]
        ↓
Stored in SQLite:
release_dates table:
  game_id=1, platform_id=7, region_id=2, release_date="2017-03-03"
